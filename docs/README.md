## 🏗️ 项目技术栈

- 前端 (Web): React 19 + TypeScript + Ant Design 5 + Framer Motion
- 前端 (Admin): React 19 + TypeScript + Ant Design 5
- 前端 (小程序): Vue 3 + uni-app
- 后端: Python FastAPI + SQLAlchemy (async) + PostgreSQL
- AI: OpenAI API / 私有模型适配器
- 部署: Docker + Nginx
