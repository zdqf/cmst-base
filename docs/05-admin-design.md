# 草木沈塘 — 管理后台设计文档

## 一、概述

管理后台是运营团队日常管理平台的核心工具，基于 React 19 + Ant Design 5 构建。

## 二、现有功能模块

### 2.1 仪表盘 (Dashboard)
- 今日核心指标：新增用户、新增订单、GMV、新增咨询
- 待处理事项：待处理订单数、待回复咨询数
- 快捷入口

### 2.2 用户管理 (Users)
- 用户列表：手机号、注册时间、最后登录、状态
- 手机号搜索
- 禁用用户（同时失效 Token）

### 2.3 中药管理 (Herbs)
- 中药列表：名称、分类、状态、操作
- 新增/编辑中药：名称、分类、来源形态、性味归经、搭配方向、不适人群、注意事项
- 上下架切换
- AI 内容生成（调用"科普内容生成"Prompt）

### 2.4 商品管理 (Products)
- 商品列表：名称、分类、价格、库存、状态
- 新增/编辑商品
- 库存调整（记录变动日志）
- 上下架切换

### 2.5 订单管理 (Orders)
- 订单列表：订单号、用户、金额、状态、时间
- 状态筛选 + 日期范围筛选
- 更新订单状态：pending → confirmed → shipped → completed / cancelled

### 2.6 咨询管理 (Consultations)
- 咨询列表：姓名、主题、状态、时间
- 状态筛选
- 更新状态 + 添加管理备注

### 2.7 问诊记录 (Diagnosis Logs)
- 问诊列表：用户、症状摘要、时间
- 按用户/日期筛选
- 查看完整问诊详情（输入 + AI 输出）

### 2.8 Prompt 模板管理 (Prompts)
- 三种模板：健康顾问、科普助手、科普内容生成
- 编辑模板内容（自动创建新版本）
- 查看版本历史
- 测试功能：输入测试数据，查看 AI 输出

### 2.9 合规配置 (Compliance)
- 违规词列表
- 新增/编辑/删除违规词
- 违规词 → 替换词映射

## 三、待重构/新增模块

### 3.1 仪表盘增强
**当前问题**: 仪表盘数据为静态，缺少图表

**重构方案**:
- 接入真实统计 API
- 添加 ECharts / AntV 图表：
  - 近 7 天/30 天 GMV 趋势折线图
  - 商品销量 Top 10 柱状图
  - 用户增长趋势
  - 订单状态分布饼图
  - AI 问诊使用量趋势
- 实时刷新（30s 轮询或 WebSocket）

### 3.2 会员管理（新增）
- 会员等级配置：等级名称、积分门槛、折扣比例、权益列表
- 用户积分管理：查看积分、手动调整积分
- 积分流水查看
- 会员等级分布统计

### 3.3 优惠券管理（新增）
- 优惠券模板：名称、类型（满减/折扣）、面值、使用门槛、有效期
- 发放方式：全员发放、指定用户、兑换码
- 使用统计：领取数、使用数、核销率

### 3.4 内容管理（新增）
- Banner 管理：首页轮播图配置
- 公告管理：系统公告发布
- 文章管理：科普文章编辑（富文本）

### 3.5 数据分析（新增）
- 销售分析：GMV、客单价、复购率
- 用户分析：新增、活跃、留存
- 商品分析：销量、库存周转
- AI 分析：问诊量、搭配查询量
- 导出报表（Excel）

### 3.6 物流管理（新增）
- 发货操作：填写快递公司、运单号
- 物流状态同步
- 批量发货

## 四、权限体系设计

### 当前
- 简单的 `is_admin` 布尔字段
- 所有管理员拥有全部权限

### 规划（v2.0）
```
超级管理员
├── 用户管理（查看、禁用）
├── 内容管理（中药、文章、Banner）
├── 商品管理（CRUD、库存）
├── 订单管理（查看、状态更新、发货）
├── 财务管理（销售数据、退款）
├── 系统配置（Prompt、合规、会员等级）
└── 数据分析（全部报表）

运营管理员
├── 内容管理
├── 咨询管理
├── 数据分析（部分）
└── 优惠券管理

客服
├── 咨询管理（查看、回复）
├── 订单管理（查看）
└── 用户管理（查看）
```

## 五、Admin 端技术重构建议

### 当前状态
- 使用 Ant Design 但未充分利用 ProComponents
- 页面样式较基础
- 缺少数据可视化

### 重构方向
1. 引入 `@ant-design/pro-components`（ProTable、ProForm）简化 CRUD
2. 引入 `@ant-design/charts` 或 ECharts 做数据可视化
3. 统一表格操作模式（搜索、筛选、批量操作）
4. 添加操作确认弹窗和成功提示
5. 响应式适配（平板可用）
6. 暗色主题支持
