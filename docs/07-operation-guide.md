## 二、内容管理规范

### 2.1 中药科普内容标准

每味中药必须包含以下字段：

| 字段 | 要求 |
|------|------|
| 名称 | 标准中药名 |
| 分类 | 补益药/清热药/解表药/理气药/活血药 等 |
| 来源与形态 | 植物来源、产地、采收加工方法 |
| 性味归经 | 四气五味、归经 |
| 常见搭配方向 | 经典配伍，注明"搭配方向"而非"处方" |
| 不适合人群 | 禁忌人群 |
| 注意事项 | 用量参考、配伍禁忌 |

**内容审核流程**:
1. AI 生成初稿（管理端"AI 内容生成"功能）
2. 中医师审核修改
3. 合规词检查
4. 管理员发布上架

### 2.2 禁用词汇

以下词汇在所有面向用户的内容中禁止使用：

| 禁用词 | 替换为 |
|--------|--------|
| 治愈 | 调理方向 |
| 治疗 | 健康参考 |
| 疗效承诺 | 传统用法参考 |
| 根治 | 调理建议 |
| 药效 | 传统功效 |
| 处方 | 搭配思路 |

## 三、客服规范

### 3.1 咨询回复模板

**首次回复**:
```
您好，感谢您对草木沈塘的信任！
我是您的专属健康顾问 [姓名]，已收到您的咨询。
关于您提到的 [主题]，我会尽快为您解答。
如需更快速的沟通，欢迎添加我们的企业微信：caomushentang
```

**产品推荐**:
```
根据您的情况，建议您可以了解一下我们的 [产品名称]。
这款产品 [简要描述]，适合 [适用人群]。
温馨提示：本建议仅供参考，如有健康问题请咨询专业医师。
```

### 3.2 注意事项

- 绝不做医疗诊断或治疗承诺
- 所有建议后附加免责声明
- 遇到紧急健康问题，引导用户就医
- 保护用户隐私，不泄露个人信息

## 四、订单处理流程

```
新订单 (pending)
    ↓ 确认库存和支付
已确认 (confirmed)
    ↓ 打包发货，填写快递单号
已发货 (shipped)
    ↓ 用户确认收货 / 7天自动确认
已完成 (completed)

异常流程:
- 库存不足 → 联系用户协商 → 取消/换货
- 用户申请取消 → 未发货可直接取消 → 已发货需协商
- 退款 → 确认收到退货 → 原路退款
```

## 五、数据指标体系

### 5.1 核心指标 (North Star)

| 指标 | 定义 | 目标 |
|------|------|------|
| 月 GMV | 月度总交易额 | 逐月增长 15%+ |
| 月活用户 (MAU) | 月度活跃用户数 | 逐月增长 20%+ |
| 复购率 | 30天内再次购买的用户比例 | > 30% |

### 5.2 过程指标

| 指标 | 定义 |
|------|------|
| 注册转化率 | 访问→注册 |
| 问诊转化率 | 注册→完成问诊 |
| 购买转化率 | 问诊→下单 |
| 客单价 | 平均订单金额 |
| AI 问诊量 | 日/周/月问诊次数 |
| 咨询响应时间 | 咨询提交到首次回复的时间 |

## 六、应急预案

| 场景 | 处理方案 |
|------|---------|
| AI 服务不可用 | 返回友好提示，引导用户稍后重试或联系客服 |
| 数据库故障 | 切换只读模式，通知技术团队 |
| 支付异常 | 暂停下单入口，排查后恢复 |
| 内容违规投诉 | 立即下架相关内容，审核后决定是否恢复 |
| 大量恶意请求 | Nginx 限流 + IP 封禁 |
