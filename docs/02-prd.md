## 一、产品概述

- 产品名称: 草木沈塘

## 三、核心用户流程

### 3.1 新用户首次体验流程

```
访问首页 → 浏览科普内容 → 注册账号
    → 尝试 AI 问诊（免费 1 次）
    → 查看调理建议 → 推荐相关商品
    → 加入购物车 → 下单购买
    → 引导加入会员 → 持续复购
```

### 3.2 AI 问诊流程

```
填写健康表单（年龄、性别、症状、过敏史、用药情况）
    → 提交至后端
    → 后端组合 Prompt 模板 + 用户输入
    → 调用 AI 服务（OpenAI / 私有模型）
    → AI 输出经过合规词过滤
    → 追加免责声明
    → 记录问诊日志
    → 返回结果给用户
    → 结果页展示 + 推荐相关商品
```

### 3.3 购物下单流程

```
浏览商品 → 加入购物车 → 调整数量
    → 进入结算页 → 选择收货地址
    → 确认订单 → 支付
    → 后端校验库存 → 扣减库存 → 创建订单
    → 支付成功 → 订单状态更新
    → 商家发货 → 物流追踪
    → 确认收货 → 评价
```

## 四、待开发功能详细需求

### 4.1 收货地址管理

**用户故事**: 作为用户，我需要管理我的收货地址，以便下单时选择。

**功能点**:
- 新增地址：收货人、手机号、省市区、详细地址、是否默认
- 编辑地址
- 删除地址
- 设为默认地址
- 下单时选择地址
- 最多保存 10 个地址

### 4.2 支付系统

**用户故事**: 作为用户，我需要在线支付订单。

**功能点**:
- 微信支付（JSAPI / H5 / Native）
- 支付宝支付（PC / H5）
- 支付回调处理
- 订单超时自动取消（30 分钟）
- 退款流程

### 4.3 优惠券系统

**用户故事**: 作为用户，我希望使用优惠券降低购买成本。

**功能点**:
- 优惠券类型：满减券、折扣券、新人券
- 领取方式：手动领取、自动发放、兑换码
- 使用规则：满额使用、品类限制、有效期
- 下单时选择优惠券
- 优惠券核销

### 4.4 会员积分系统（后端）

**用户故事**: 作为会员，我希望通过消费和互动获取积分，享受更多权益。

**功能点**:
- 积分获取：消费、签到、问诊、分享、评价
- 积分消耗：兑换优惠券、抵扣现金（100积分=1元）
- 等级计算：根据累计积分自动升降级
- 积分流水记录
- 积分过期机制（年度清零）

### 4.5 商品评价系统

**用户故事**: 作为用户，我希望查看其他人的评价来辅助购买决策。

**功能点**:
- 订单完成后可评价
- 评分（1-5 星）+ 文字评价 + 图片
- 评价列表展示在商品详情页
- 好评率统计
- 管理端审核评价

### 4.6 数据分析仪表盘（Admin）

**功能点**:
- 今日/本周/本月 GMV、订单数、新增用户
- 销售趋势图（折线图）
- 商品销量排行（柱状图）
- 用户转化漏斗（访问→注册→问诊→下单）
- AI 问诊使用统计
- 会员等级分布（饼图）

| 维度 | 要求 |
|------|------|
| 性能 | 页面首屏加载 < 2s，API 响应 < 500ms |
| 可用性 | 99.9% 可用性，支持水平扩展 |

| 合规 | AI 输出合规过滤、免责声明、医疗用语规避 |
